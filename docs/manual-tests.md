# 手動確認の手順

自動テスト（Playwright）では再現しきれない操作を、実機の Chrome / Edge で確認する。
リリース前と、`packages/editor` の構造ガード・IME まわりを変更したときに実施する。

各項目の確認後、保存したファイルを元ファイルと `diff` して、変更箇所以外に差分がないことを確かめる。

```bash
diff -u original.html saved.html
```

## MT-01 日本語IME：変換・確定（AC-05）

1. `fixtures/basic.html` を開き、段落の途中にカーソルを置く。
2. macOS の日本語入力（またはGoogle 日本語入力）で「へんしゅう」と入力し、スペースで「編集」に変換して Enter で確定する。
3. 期待：確定した文字だけが入り、段落が分割されない。変更箇所一覧に1件出る。
4. 保存し、差分がその段落の中だけであることを確認する。

## MT-02 日本語IME：キャンセル（AC-05）

1. 段落の途中で「かくにん」と入力し、未確定のまま Esc で取り消す。
2. 期待：テキストは元のまま。変更箇所一覧に何も出ない。未保存の表示も出ない。
3. 変換中に別の段落をクリックした場合も、確定または取り消しのどちらかで正しく終わることを確認する。

## MT-03 中身を全部消した要素（AC-06、既知の制約）

1. `fixtures/basic.html` の段落の中身を全部選択して BackSpace で消す。
2. 期待：要素は残り、`<br>` は入らない。要素の高さが 0 になり、クリックできなくなることがある（既知の制約）。
3. Ctrl+Z で元に戻ることを確認する。
4. もう一度消し、変更箇所一覧の「この変更を戻す」で元に戻ることを確認する。
5. 消したまま保存し、保存後に Ctrl+Z で元に戻ること、再度保存すると元ファイルとバイト一致することを確認する。

## MT-04 日本語IME：境界での入力

1. `fixtures/inline.html` の `<strong>` の直後にカーソルを置き、IME で入力して確定する。
2. 期待：入力が隣接する既存のテキストノードに入り、新しい要素やテキストノードが増えない。

## MT-05 本物のファイル選択ダイアログ（AC-10）

自動テストではファイル選択ダイアログを偽物に差し替えているため、本物のダイアログでの動作はここで確認する。作業用にコピーしたファイルで行う。

1. 「ファイルを開く」で `basic.html` のコピーを開く。初回は Chrome がファイルの閲覧を許可するか尋ねる。
2. 1箇所直して Ctrl+S で保存する。初回は Chrome が書き込みを許可するか尋ねる。許可すると上書き保存され、`diff` に直した箇所だけが出る。
3. 「別名で保存」を押す。ダイアログに元のファイル名が入っていること、同じフォルダが開くことを確認する。キャンセルすると何も書き込まれず、未保存の表示が残る。
4. 別名で保存すると新しいファイルができ、ヘッダーのファイル名が変わる。元のファイルは変わらない。
5. Finder からファイルをドロップしても開けることを確認する。

## MT-06 最近開いたファイル（F-06）

最近開いたファイルは本物のファイルでないと IndexedDB に保存できないため、自動テストの対象外。

1. ファイルを2つ開いた後、ロゴを押して最初の画面に戻る。2つとも新しい順に並び、ファイル名と日付だけが表示される（パスは出ない）。
2. 同じファイルをもう一度開いても、一覧に重複して出ない。
3. ブラウザのタブを閉じて開き直し、一覧から開く。Chrome が閲覧の許可を尋ね、許可すると開ける。拒否すると「ファイルを開けませんでした」の説明が出る。
4. 一覧にあるファイルを Finder で削除または移動してから一覧から開くと、開けない理由が表示され、画面が壊れない。

## MT-07 改行の入力（AC-12）

1. `fixtures/basic.html` のコピーを開き、段落の途中で Shift+Enter を押す。行が分かれ、変更箇所一覧の変更後に「↵」が出る。
2. 分かれた行の先頭で BackSpace を押すと、行がつながる。Ctrl+Z で分かれた状態に戻る。
3. 段落の末尾で Shift+Enter を押し、日本語IME（Microsoft IME と Google 日本語入力）で入力して確定する。入力した文字が新しい行に入る（前の行の末尾に入らない）。
4. 保存して `diff` を取り、`<br>` と入力した文字だけが増えていることを確認する。
5. `fixtures/pre.html` のコピーの `<pre>` の中で Enter を押すと改行文字が入り、保存するとその改行だけが増える。CRLF のファイルでは CRLF になる。
